# **MultiTools** 🛠️

O **MultiTools** é uma aplicação desenvolvida em **Flet Python**, projetada para oferecer múltiplas ferramentas em um único local. Com funcionalidades que incluem teste de velocidade de internet, previsão do tempo e gerenciamento de downloads do YouTube, o MultiTools é ideal para usuários que buscam praticidade e eficiência em uma interface moderna.

## **🚀 Funcionalidades**

1. **Teste de Velocidade de Internet**
   - Mede a velocidade de download e upload em tempo real.
   - Interface responsiva com animações durante o teste.
   - Indicadores coloridos para o status das velocidades.

2. **Previsão do Tempo**
   - Página dedicada para exibir informações climáticas (em desenvolvimento).

3. **Downloader do YouTube**
   - Gerencia downloads diretamente da plataforma YouTube (em desenvolvimento).

4. **Interface Intuitiva**
   - Navegação simplificada entre funcionalidades.
   - Alternância entre temas claro e escuro para maior conforto visual.

## **🔧 Configuração do Ambiente**

### **Pré-requisitos**

Certifique-se de ter o **Python 3.12** ou superior instalado em sua máquina.

### **Instalação**

1. Clone o repositório:
   ```bash
   git clone https://github.com/Alisonsantos77/MultiTools.git
   cd MultiTools
   ```

2. Crie um ambiente virtual:
   ```bash
   python -m venv venv
   source venv/bin/activate  # No Windows: venv\Scripts\activate
   ```

3. Instale as dependências necessárias:
   ```bash
   pip install -q -U flet
   pip install -q -U speedtest-cli
   ```

### **Execução**

Inicie a aplicação com o seguinte comando:
```bash
flet run main.py
```

## **🌟 Funcionalidades por Página**

   - Mede velocidades de download e upload com animações e indicadores.
   - Opção de reset após a medição.

2. **Previsão do Tempo**

3. **YouTube Downloader**
